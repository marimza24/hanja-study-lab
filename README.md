# Hanja Study Lab — 한자 함께 공부하기

Sitio estático en español para organizar actividades del grupo colaborativo de Hanja.

## Incluye
- Exploración visual de caracteres Hanja.
- Mini cuestionario para relacionar caracteres y vocabulario coreano.
- Guía de estructura para encuentros colaborativos.
- Mesa de aportes local para proponer palabras y preguntas.

## Publicar en Netlify
1. En Netlify, elige **Add new site → Import an existing project** y conecta este repositorio.
2. Deja vacío el comando de build.
3. Usa `.` como directorio de publicación.
4. Publica el sitio.

La mesa de aportes usa `localStorage`: los datos quedan en ese navegador y no se sincronizan entre integrantes. Para colaboración en tiempo real habrá que conectar un backend como Supabase o Firebase.
